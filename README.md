پروژه تمرینی اضافه کردن کاربر (Add users)
توضیحات کلی
این پروژه یک اپلیکیشن ساده‌ی برای اضاف کردن کاربر است که با React ساخته شده. کاربران می‌توانند با وارد کردن اطلاعات نام و سن خود: • اطلاعات کاربر جدید اضافه کنند • اطلاعات ثبت شده را مشاهده کنند • در صورت خالی بودن فیلد نام و به درستی وارد نکردن سن یک پیغام خطای مناسب دریافت کنند
این پروژه بیشتر روی مفاهیم ارتباط بین کامپوننت‌ها، استفاده از ref و همچنین موضوع fragment در ری‌اکت تمرکز دارد.
